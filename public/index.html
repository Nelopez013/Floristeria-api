Floristería API

API REST para la gestión de una floristería

Node.js · Express · MongoDB Atlas · JWT · Swagger

Abrir Swagger Ver GitHub

¿Qué es este proyecto?

Esta API REST permite administrar la información de una floristería utilizando una arquitectura basada en servicios web.

Node.js + Express

Desarrollo del servidor y endpoints REST.

MongoDB Atlas

Persistencia de los datos en la nube.

JWT

Autenticación y control de acceso.

Swagger

Documentación y prueba de los endpoints.

¿Cómo utilizar la API?

1. Autenticarse

Primero se debe iniciar sesión mediante el endpoint:

POST /api/auth/login

El servidor devuelve un token JWT.

2. Autorizarse

En Swagger se debe utilizar el botón Authorize.

Allí se ingresa el token JWT para poder probar los endpoints protegidos.

3. Probar endpoints

Después de autenticarse se pueden consultar, crear, actualizar o eliminar recursos según los permisos del usuario.

Endpoints de la API

Los siguientes endpoints están disponibles en el sistema.

Autenticación

POST /api/auth/login

Inicia sesión y genera un token JWT.

Público

Clientes

GET /api/clientes

Obtener todos los clientes.

JWT

Obtener un cliente específico.

JWT
POST /api/clientes

Crear un nuevo cliente.

JWT
PUT /api/clientes/{id}

Actualizar un cliente existente.

JWT
DELETE /api/clientes/{id}

Eliminar un cliente.
